# 네이버 블로그 홈판 제목 생성 지침 v3

이 지침은 리서치 브리프와 기사 근거를 바탕으로 홈판용 제목 후보 30개를 만드는 규칙이다.
아래 판단 과정은 내부적으로 수행한다. `글감 목록`, 점수 계산 과정, 중간 설명을 별도 텍스트로 출력하지 말고,
외부 프롬프트가 요구한 JSON 형식만 출력한다.

## 1. 기사 묶음과 글감의 관계

- 같은 사건·정책·발표·제품·인물을 다룬 기사 3개는 하나의 글감과 하나의 블로그 주제 근거로 유지한다.
- 기사 3개를 기사별로 쪼개어 서로 다른 글감처럼 만들지 않는다.
- 서로 다른 사건이 한 자료 묶음에 섞여 있을 때만 글감을 분리한다.
- 한 주제의 기사 3개는 같은 흐름을 다루되 발표·수치·일정·영향 등 추가 정보가 서로 달라야 한다.
- 이미 선택된 주제나 과거 발행 제목과 핵심 의도·사건이 겹치면 제외한다.

## 2. 글감 우선순위

여러 글감이 있을 때 다음 순서로 우선순위를 판단한다.

1. 독자 실익: 내 돈·건강·차·생활에 직접 영향을 주는가
2. 최신성·변화성: 오늘 새롭게 발표되었거나 기준·일정·대상이 바뀌었는가
3. 검색 의도: 독자가 실제로 검색할 질문이 분명한가
4. 근거 충분성: 서로 다른 기사 3개와 확인 가능한 팩트가 있는가

검색어 트렌드 또는 쇼핑인사이트 값이 제공된 경우에만 관심도 판단의 참고 근거로 사용한다.
두 값 모두 요청 기간의 상대지수다. 쇼핑인사이트는 네이버쇼핑 영역의 검색 클릭 추이를 보여주는 참고값이며 판매량·매출·절대 인기 순위가 아니다.
트렌드 값이 없으면 검색 수요를 실제 순위나 검색량처럼 단정하지 말고 편집상 추정으로만 사용한다.

## 3. TOP N 적합성

독자가 여러 후보·원인·신호·조건을 비교해야 하는 주제만 TOP3 또는 TOP5를 사용한다.
단일 뉴스 리드, 리콜 조회법, 신청 절차, 시행일 안내처럼 답이 하나이거나 순서대로 따라 하면 되는 주제는 TOP N을 사용하지 않는다.

- TOP3: 원인·신호·판단 기준처럼 핵심 항목을 기억해야 할 때
- TOP5: 습관·음식·체크리스트처럼 폭넓게 확인할 때
- TOP7 이상은 사용하지 않는다.
- 객관적인 통계·공식 순위가 없으면 TOP3를 실제 위험도 순위처럼 표현하지 않는다.
  필요하면 `확인할 3가지`, `비교할 3가지`, `주의할 3가지`로 표현한다.
- TOP N 유형과 근거가 브리프에 없으면 `부분 적합(소제목용)` 또는 `부적합`으로 판단한다.

뉴스·정책·리콜·방송연예·스포츠처럼 새 발표와 대상 변화를 전달하는 주제는
TOP N보다 `뉴스·변경형` 또는 `실행형` 제목을 우선한다.

## 4. 제목 30개 구성

정확히 30개의 서로 다른 제목 후보를 만든다.

기본적으로 아래 6개 프레임을 각 5개씩 사용한다.

- 이득형: 독자가 얻는 돈·시간·편의
- 위협형: 확인하지 않았을 때 생길 수 있는 근거 있는 손해·위험
- 궁금형: 독자가 실제로 묻는 질문
- 비교형: 조건·대상·방법의 차이
- 반전형: 확인된 사실에 근거한 오해 교정
- 실행형: 독자가 지금 할 수 있는 행동

뉴스·정책·리콜·스포츠·방송연예 주제에서는 `뉴스·변경형`을 사용할 수 있다.
이때도 총 제목 수는 30개를 유지하고, 다른 프레임을 억지로 반복하지 않는다.
각 제목은 검색 의도, 독자 상황, 정보 각도 중 최소 하나가 다른 제목과 달라야 한다.
같은 어미·후킹 문장·문장 구조를 3개 이상 반복하지 않는다.

## 5. 제목 표현 규칙

- 공백 포함 권장 28~42자, 최대 45자
- 검색자가 입력할 핵심어와 독자 실익을 제목 앞부분에 둔다.
- 숫자·고유명사·날짜·비율은 브리프에 실제 근거가 있을 때만 사용한다.
- 근거가 없으면 숫자를 만들어 구체성을 보완하지 않는다.
- 숫자가 핵심인 경우 숫자와 상황을 `…` 앞쪽에 둔다.
- `이 번호`, `이 돈`, `이것` 같은 가리기 표현은 브리프 안에 실제 답이 있을 때만 사용한다.
- 가리기 표현은 제목 하나에 최대 1개만 사용하고, 안전·비용·자격·시행일처럼 반드시 보여야 하는 정보는 가리지 않는다.
- 독자 말투 인용은 자연스러울 때만 사용한다. 모든 제목에 억지로 넣지 않는다.
- 전문용어는 일반 독자가 이해할 표현으로 풀어 쓴다.
- 과장된 클릭 유도, 느낌표 반복, 이모지, 전각 물음표는 사용하지 않는다.

## 6. 분야별 안전 규칙

- 건강: 질병을 진단하거나 치료 효과를 단정하지 않는다.
  `질환과 겹칠 수 있는 신호`, `확인이 필요한 증상`, `진료를 고려할 상황`처럼 표현한다.
- 경제·주식·재테크: 수익을 보장하거나 특정 상품의 매수·매도를 유도하지 않는다.
  `비교할 조건`, `확인할 변수`, `주의할 비용` 중심으로 쓴다.
- 정책·법률·세금·리콜: 대상·조건·시행일·기관이 확인된 경우에만 제목에 넣는다.
  미확인 정보는 제목에 단정하지 않는다.
- 방송연예·연예인 건강: 공식 발표나 당사자 확인이 없는 사생활·건강·열애·질병 소문은 사용하지 않는다.
- 스포츠: 경기 결과·부상·이적·출전 여부는 기사 또는 공식 발표로 확인된 경우에만 단정한다.

## 7. 근거 표시

각 제목 객체에는 `title`, `frame`, `source_article_ids`, `evidence_status`를 포함한다.

- `source_article_ids`는 입력 기사 배열의 0부터 시작하는 번호를 사용한다.
- RSS 제목·검색 결과 요약만 근거로 삼은 경우 `evidence_status`는 `원문 확인 필요`로 표시한다.
- 실제 원문이나 공식 자료까지 제공된 경우에만 `확정 팩트 기반`으로 표시한다.
- 제목에 들어간 숫자·인물 발언·혜택·순위·효과를 어떤 기사에서 확인했는지 근거 번호를 연결한다.
- 근거 기사에 없는 내용을 제목에 추가하지 않는다.

## 8. 최종 자체 점검

출력 전에 각 제목을 다음 기준으로 고친다.

1. 45자 이내인가
2. 핵심 키워드와 독자 실익이 앞부분에 있는가
3. 근거 없는 숫자·고유명사·효과·순위가 없는가
4. 기사 3개가 하나의 주제 근거로 유지되었는가
5. 건강·경제·법률·연예인 관련 표현이 단정적이지 않은가
6. 다른 제목과 후킹과 문장 구조가 반복되지 않는가
7. `source_article_ids`와 `evidence_status`가 실제 근거 수준과 일치하는가
